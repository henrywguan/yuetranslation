# Poly Haven (CC0) — HarborRPG sample pack

Small curated starter set of **CC0** HDRIs, PBR ground textures, and a few prop models from [Poly Haven](https://polyhaven.com).

- **License:** CC0 (public domain) — see [Poly Haven License](https://polyhaven.com/license)
- **Full list + sizes:** [INVENTORY.md](./INVENTORY.md)
- **Not** a full catalog dump — fantasy outdoor lighting + ground materials only

Use HDRIs for scene IBL / sky lighting; tile texture sets on terrain/paths; drop glTF props for quick scenic clutter.
